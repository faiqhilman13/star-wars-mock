# Character sheet generation

Tool: built-in imagegen (not API/CLI). 3D model construction remains entirely local Blender.

Approved design input: approved-concept.png. Helmet detail input: helmet-detail.png.

## Turnaround prompt
Create a precise production turnaround character sheet of the EXACT approved helmeted dark caped sci-fi knight in the reference image. Preserve every distinctive feature: fitted tapered skull-mask metal helmet with black lenses and slotted lower faceplate, segmented gunmetal armor, charcoal padded undersuit, leather belt and pouches, asymmetrical front cloth panels, armored knees and boots, dark weathered cape and folded hood at neck. Wide landscape sheet, FOUR separate full-body orthographic views in one evenly spaced row: FRONT, LEFT SIDE, BACK, RIGHT SIDE. All views of the identical character at identical scale and floor baseline, neutral symmetrical relaxed stance, arms slightly away from torso, hands open relaxed, feet pointing forward. No weapon in hands to avoid obscuring model. Cape falls naturally to lower calves, hood down. Front armor must exactly match reference panel layout. Side and back are consistent interpretations of this same costume. No redesign, no extra plates, no larger helmet, no stylization change. Neutral diffuse studio light, plain near-white background, crisp readable forms and material boundaries for 3D modeling. Full helmet and boots within canvas with generous margins, no perspective, no dramatic shadows. Small simple labels beneath each view only: FRONT, LEFT, BACK, RIGHT.

## Action reference prompt
Create a professional game character ACTION REFERENCE SHEET of the EXACT helmeted dark caped armored knight in the supplied image. Preserve the same fitted skull-mask gunmetal helmet, black eye lenses, segmented chest armor, dark padded suit, asymmetric waist cloth, belt pouches, knee armor, boots, weathered charcoal cape and single white lightsaber. Eight distinct full-body poses in a spacious 4-column by 2-row grid, each completely contained in its own cell including cape and blade. Labels beneath cells, exact: IDLE, WALK, RUN, JUMP, ATTACK, PARRY, DODGE, LAND. Idle balanced ready stance. Walk clear mid-stride. Run dynamic sprint with cape trailing. Jump airborne knees bent. Attack powerful diagonal saber cut. Parry two-handed defensive saber guard. Dodge low lateral evasive step. Land crouched soft landing. Consistent character proportions, costume construction and helmet identity in every cell. Right-handed saber grip with left hand supporting when appropriate. View each from clear three-quarter angle, readable poses and limb separation, no enemies or scenery, no impact effects, no motion blur. Neutral pale grey background, consistent soft studio lighting, high detail semi-realistic game concept rendering matching reference. This is a pose concept sheet, not animation frames. No cropped figures, no overlapping cells, no redesign.

## Inspection limitations
The generated profiles contain yaw; not exact orthographic geometry. Cape hem and tiny surface details vary between views. Action sheet parry and dodge blades are cropped, so weapon length cannot be measured there. Existing gameplay saber is blue and remains independent of the concept's white blade. No animation data is contained in these images.
